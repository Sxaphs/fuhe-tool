# fuhe-tool · 产品介绍视频简报（供 huashu-motion 使用）

> 本文档是给 [huashu-motion](https://github.com/alchaincyf/huashu-motion)（或任何 coding agent）拍摄 fuhe-tool 产品介绍片的**完整输入**。
> 开工前请先用 `om grab` 抓取产品真实素材（网页截图、颜色、界面），再按下面档案出三个方向关键帧给用户选择。
> 本机渲染注意：Windows 环境请始终 `--workers 2`（默认 8 路 Chrome 会压超时，见本机经验）。

## 一、产品档案（一句话 + 完整事实）

**一句话定位**：留学学历认证复核一条龙——上传成绩单，自动识别、自动比对 985/211 课表、自动出复核建议报告的开源免费工具。

**完整事实**（片中可用的数字与名称）：

| 事实 | 数据 |
|---|---|
| 产品名 | fuhe-tool |
| 在线地址 | https://sxaphs.github.io/fuhe-tool/ |
| GitHub | https://github.com/Sxaphs/fuhe-tool（MIT 开源） |
| 目标用户 | 想报考公务员、需要做教育部留服中心「专业名称复核」的留学回国人员 |
| 输入 | 成绩单（PDF / 手机截图 / CSV / TXT）+ API Key + 目标复核专业（本科专业或研究生学科，如"应用经济学 0202"） |
| 自动流水线 | 识别成绩单 → 匹配专业 → 找各校培养方案比对 → 生成复核建议报告（可导出 PDF） |
| 识别能力 | PDF 文字层直提；手机截图用视觉模型 AI 识别（Moonshot/OpenRouter），未配置时本地三语 OCR 兜底（德语+英语+中文） |
| 数据资产 | 74 个常见本科专业 × 464 门双语课程；55 个研究生一级学科（含代码 0202 应用经济学等）；税务系统公务员专业目录 60 类 / 835 专业 |
| 课表比对 | 本地已收录真实培养方案 + AI 自动整理各校课程并语义匹配 + 用户可直接上传培养方案 |
| 隐私承诺 | 全程浏览器本地处理：API Key 只存本机 localStorage，成绩单文件不出设备，无任何后端服务器 |

**内容红线**（画面与文案都不得违反）：
- 不得出现「包过」「保证通过」「100% 成功」等承诺性表述（复核结果由留服中心审核决定，工具定位是"自助整理与参考"）；
- 免责声明可以自然呈现（例如片尾小字"仅供申报参考，最终以留服中心审核为准"）。

## 二、建议成片规格

- 时长：**30–45 秒**（16:9 为主；如需抖音版可另做 2:3 竖屏 + 中文口播）
- 节奏单：**3 秒内钩子**（痛点画面），中段一次爆发（快切+最大响点前停一拍），结尾收在品牌与仓库地址
- 配乐：默认兜底配乐按"工具/开发者产品"类选择，或作曲家模式写谱；BPM 建议 120–128
- 声音：口播可选（macOS 系统音色或用户录音）；无口播时用大字号中文字幕叙事
- 结尾：品牌字标「fuhe-tool」+ GitHub 地址 + 一行小字免责声明

## 三、三个方向（给用户挑，可组合）

**方向 A · 一条龙流水线（推荐）**
成绩单（纸张/PDF/截图）投入 → 识别出的课程名一个个弹出并自动"盖章"核对 → 专业名+代码落定（应用经济学 0202）→ 各校培养方案卡片依次比对亮起重合度 → 报告生成、表格逐行填满 → 导出 PDF。
镜头语言：纸面→数字化 的流水线隐喻，元素按拍子落地，蓝色主线贯穿。

**方向 B · 隐私盾牌**
"你的成绩单、你的 Key、你的电脑"——文件与 Key 从未离开浏览器：Key 存本机的锁扣动画、文件在本地的围栏、请求直连服务商的线。适合强调开源免费与无服务器架构。
镜头语言：盾/锁/围栏符号 + 数据流动线，暗底亮蓝。

**方向 C · 考公上岸**
留学生（学位帽+成绩单）→ 复核专业与公务员岗位目录对钩 → 上岸终点（录取通知轮廓）。情绪向，适合抖音/小红书传播。
镜头语言：目标线叙事，绿色对钩与琥珀色节点。

## 四、品牌与视觉

- 主色：`#2563eb`（蓝，动作与主元素）；深色 `#1e3a8a`（渐变底）；辅助 `#16a34a`（绿·匹配通过）、`#d97706`（琥珀·提示）、`#dc2626`（红·失败/警告）；背景 `#f8fafc` 亮纸面
- 字体：中文黑体优先（如系统苹方/微软雅黑），数字与代码可用等宽
- 无官方 logo：可用「fuhe-tool」字标 + 蓝色圆角方块（呼应网页卡片圆角 12px 风格）自造
- 界面素材：`om grab` 抓取三个页面——主页（一条龙表单）、考公目录（专业查询表）、分析结果（步骤卡片 + 学校重合度表格 + 课程对应表）

## 五、镜头/场景清单（方向 A 细化，供 agent 直接排）

1. **钩子（0–3s）**：一张国外成绩单掉进画面，认证报告上的专业名与考公目录对不上——两个名字之间的红色错位标记。
2. **承诺（3–6s）**：主标题「留学认证复核，一条龙」+ 副标「上传成绩单，自动出复核建议」。
3. **输入（6–12s）**：三样东西依次落地：API Key（存本机锁图标）、成绩单（PDF/截图图标）、目标专业（下拉选择，落在「应用经济学 · 0202」）。
4. **流水线爆发（12–26s）**：四步流水线快切——识别课程表（课程名逐个弹出）→ 匹配专业（重合度进度条）→ 学校课表比对（清华/北大等卡片亮起）→ 报告表格逐行填满（课程对应表）。
5. **隐私点（26–32s）**：数据流动线在本机循环，「Key 不出设备 · 文件不出浏览器 · 无服务器」。
6. **结尾（32–40s）**：开源徽标 MIT + 字标 fuhe-tool + 仓库地址 https://github.com/Sxaphs/fuhe-tool + 免责小字。
